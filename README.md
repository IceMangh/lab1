
## Запуск

Нужны Python 3 и компилятор C++20. Из папки проекта:

```sh
python3 server.py
```

Браузер откроется по адресу http://127.0.0.1:8766/. Остановка — `Ctrl+C`.

В CLion откройте проект и запустите цель `lab1_gui`.
